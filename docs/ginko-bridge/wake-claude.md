# Claude 离线时的人工唤醒兜底

先按 [clients](clients.md) 检查本频道成员、正式应用hooks/socket能力和获准代理环境。who认证成功但online=false仅表示监听离线，不证明token失效；不重新join，不在终端启动另一Claude冒充应用接收端。

自动唤醒不可用时，由用户打开本频道原Claude应用接收对话，发送一句人工提示：「请按既有规则查看本频道待收消息；先按编号去重，保留已有结果，不重跑已完成或结果不明任务。」提示本身不重发业务正文，不代表允许消费此前明确隔离的旧消息。

接收对话在自己的正式执行环境核对真实session和频道，复用原绑定恢复本session监听；若该应用支持并且用户允许处理队列，才通过标准inbox读取（会ACK），先保留处理结果，再按原任务范围处理。不能从实施对话读取受限session、借用token或手动ACK清积压。

若缺正式hook/socket/执行能力或原对话不可达，报告具体缺口并继续保留消息和账本；不要宣称已唤醒/已接收，不另建常驻服务。恢复后按 [verify](verify.md) 分别验证在线、接收、处理和回复证据。
